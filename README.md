# Face Detection and Attendance Management System

Face Detection and Attendance Management System using Python and OpenCV.

## Technologies Used
- Python
- OpenCV
- Jupyter Notebook

## How it works
- COLLECT_DATA_01 - Face data collect karta hai
- CONSOLIDATED_DATA_01 - Data ko clean aur ready karta hai
- Face_Detection_01 - Face detect karta hai
- Attendance_logic - Attendance mark karta hai
- RECOGNISE_01 - Face ko pehchanta hai
